## Runtime sequence

![Sequence](sequence.svg)

```mermaid
sequenceDiagram
  autonumber
  participant PU as User
  participant PO as Orchestrator
  participant P01 as 01 Validation
  participant P02 as 02 Metrics
  participant P04 as 04 Trends
  participant P05 as 05 Anomalies
  participant P03 as 03 Quality
  participant P06 as 06 Risk
  participant P07 as 07 Coach
  participant P08 as 08 Evidence
  participant P09 as 09 Dashboard
  participant P10 as 10 Report
  participant PC as AI subagents
  PU->>PO: python run.py
  Note over PO: clean slate: delete previous agent outputs
  PO->>P01: run()
  P01-->>PO: WARN
  alt 01 status = FAIL (un-excepted CRITICAL issue)
  PO-->>PU: BLOCKED + blocking issues · exit 1 · nothing else runs
  PU->>PU: fix the data, or approve a documented exception
  PU->>PO: re-run → 01 revalidates
  else PASS / WARN (issues handled by directives)
  Note over PO: continue
  end
  PO->>P02: run()
  P02-->>PO: PASS
  par parallel layer
  PO->>P04: run()
  P04-->>PO: PASS
  and
  PO->>P05: run()
  P05-->>PO: PASS
  end
  PO->>P03: run()
  P03-->>PO: PASS
  PO->>P06: run()
  P06-->>PO: PASS
  PO->>P07: run()
  P07-->>PO: PASS
  PO->>P08: run()
  P08-->>PO: WARN
  loop while 08 has rerun_requests (max 2 rounds)
  PO->>P07: run(exclude = rejected findings)
  P07-->>PO: recommendations rebuilt
  PO->>P08: re-validate
  P08-->>PO: verdicts
  end
  PO->>P09: run()
  P09-->>PO: PASS
  PO->>P10: run()
  P10-->>PO: PASS
  alt an agent raises / an output check fails
  PO-->>PU: ERROR · dependants skipped · exit 1
  else all passed
  PO-->>PU: PASS · run_log.json
  end
  PU->>PO: python run.py brief
  PO-->>PU: brief.json (validated findings only)
  PU->>PC: run risk-narrator + engineering-coach-writer
  PC-->>PU: narratives_*.json
  PU->>PO: python run.py ingest
  alt narrative is stale / adds a number / claims a cause / is generic
  Note over PO: REJECT: deterministic wording kept
  else accepted
  PO->>P09: refresh dashboard with accepted narratives
  end
```
